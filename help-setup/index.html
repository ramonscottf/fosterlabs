Create Slack app at api.slack.com
  1. Open api.slack.com/apps
  2. Click Create New App → From scratch
  3. App name: Helpline
  4. Workspace: DEF (the one you and Karah use)
  5. Click Create App
Add bot scopes
In the left sidebar, click OAuth & Permissions. Scroll to Bot Token Scopes, click Add an OAuth Scope, and add each:
  1. chat:write — post messages
  2. chat:write.public — post to channels without joining
  3. channels:read — list channels
  4. channels:history — read replies
  5. users:read — resolve user names on replies
  6. files:read — handle attachments
Enable Events API
  1. Sidebar → Event Subscriptions → toggle Enable Events on
  2. Request URL: https://helpline.fosterlabs.org/slack/events
  3. Slack will ping the URL — wait for the green ✓ Verified
  4. Subscribe to bot events: message.channels
  5. Click Save Changes at bottom
Wait! The verification ping will fail until Skippy has deployed the Worker. Do Phase 1 first, ping me ("phase 1 done"), then come back to this step.
Install to DEF workspace
  1. Sidebar → Install App (or OAuth & Permissions)
  2. Click Install to Workspace
  3. Click Allow
  4. You'll get a Bot User OAuth Token starting with xoxb-... — copy it
